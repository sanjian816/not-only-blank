# 不只是留白

程乐松哲思摘录 · 三见整理

**[在线习读](https://sanjian816.github.io/not-only-blank/)**

52 则语录，六章习读。由反思走向平和，也回到每一天具体的生活。

## 怎么读

- 手机竖屏、电脑均可连续阅读。
- 六章目录、全文搜索、随机随读与收藏。
- 每则语录下可记录自己的反思，也可导出 Markdown 备份。
- 每则语录下可阅读同行者公开发表的感悟，并主动接上一段自己的想法；公开接龙免费且无需登录，需要联网。
- 可放大字号、切换夜读；书本按钮打开原版 37 页画册。
- 「分享」可复制在线阅读链接，也可下载独立 HTML 文件供离线阅读。

## 关于自己的笔记

收藏、反思与阅读进度只保存在当前浏览器，不会提交到 GitHub，也不会被放进分享文件。它们不跨设备自动同步，清除浏览器数据可能导致记录丢失；重要笔记请使用「导出我的反思」备份。

## 内容说明

语录来自整理者提供的程乐松哲思摘录，保留原文。章节次序、小标题、反思问题为编辑编排。「理解自己，重返生活」为补拟系列标题；“表演努力”页的场景补记单独标注，未冒充逐字引文。摘录未另行逐条核验外部出处。

本页用于个人习读、交流和日常自省。引文署名为程乐松；本仓库不对引文主张原创著作权，也不为引文另授开源许可。

## 文件

- `index.html`：独立习读版，含语录与常用字字体及原版画册；可下载后直接用浏览器打开。
- `.nojekyll`：GitHub Pages 直接提供静态文件。
- `FONT-LICENSES.md`：嵌入字体 Noto Serif SC、Instrument Serif 的许可证。

页面不依赖外部脚本、统计服务或登录。公共感悟接龙连接独立的妙搭服务；联网时可读写公开投稿，断网时正文、搜索、私人反思和画册仍可用。旧笔记不会自动发表；「把我的私人草稿带入发表框」只复制文字，须再次点击「公开发表」才会被其他读者看到。
